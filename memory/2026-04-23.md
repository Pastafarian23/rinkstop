## Lesson: Gateway Restart Required for New Groups (2026-04-23 01:22 UTC)

**Problem:** When adding a new Telegram group to openclaw.json, the gateway doesn't immediately recognize it. Messages from the group are not received until the gateway is restarted.

**Solution:** After adding any new group to the config:
1. Add group to channels.telegram.groups
2. Add binding to bindings array
3. Restart the gateway with 'pkill -f openclaw gateway && openclaw gateway &'

**Other groups that had this issue:**
- Home & Garden Center Philippines (-5038298893)
- Casa Azul de Cebu (-5028142945)

**Always test with a reply message after restart to confirm bidirectional works.**

## Lessons Learned (2026-04-23)
- Dropbox folder path must match existing folders; previously tried `/Arnel/Output/` which was wrong
- Use `--data-binary` with curl for file upload to preserve binary data
- Dropbox API Arg must be JSON string with escaped quotes
- Ensure correct API endpoint (`/dropbox/2/files/upload` not older endpoints)
- Monitor cron delivery status to catch delivery issues early
