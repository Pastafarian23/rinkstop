# 2026-04-17

## Kevlar Daily Brainstorm Cron Failure Alert Fix

**Issue:** Cron job "Kevlar Daily Brainstorm" was sending failure alerts even though the message was successfully delivered to the Telegram group (-5132774377). The error showed "⚠️ ✉️ Message failed" but `delivered: true` and `deliveryStatus: "delivered"`.

**Root cause (suspected):** OpenClaw platform bug where status="error" gets set based on an internal tool failure during execution, even when final message delivery succeeds.

**Fix applied:**
1. Added `--failure-alert-after 3` to require 3 consecutive true errors before alerting
2. Added `--best-effort-deliver` so delivery hiccups don't falsely mark job as error

**Commands run:**
```bash
openclaw cron edit b894ea9e-ba43-4fbf-9ffb-c23278edd44d --failure-alert-after 3
openclaw cron edit b894ea9e-ba43-4fbf-9ffb-c23278edd44d --best-effort-deliver
```

**Job ID:** `b894ea9e-ba43-4fbf-9ffb-c23278edd44d`
**Target:** Telegram group -5132774377 (Kevlar Data Ops)

**Note:** This is a platform-level issue that should be fixed in OpenClaw core — status="error" should only occur when delivery actually fails, not when internal tools hiccup during execution.
