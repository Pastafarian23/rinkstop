# SUPPORT AGENTS - QUICK START GUIDE

## Your Mission
Resolve customer issues quickly and professionally.

---

## TICKET WORKFLOW

```
1. RECEIVE → Create ticket from template
2. TRIAGE → Assign priority (URGENT/HIGH/MEDIUM/LOW)
3. RESPOND → Acknowledge within SLA
4. INVESTIGATE → Understand the issue
5. RESOLVE → Fix or answer
6. CLOSE → Confirm satisfaction
7. ESCALATE → If needed
```

---

## PRIORITY MATRIX

| Priority | Response Time | Examples |
|----------|---------------|----------|
| **URGENT** | 1 hour | Site down, can't access, major bug |
| **HIGH** | 4 hours | Feature broken, data wrong |
| **MEDIUM** | 24 hours | General questions, how-to |
| **LOW** | 48 hours | Feature requests, suggestions |

---

## ESCALATION GUIDE

| Issue Type | Escalate To |
|------------|-------------|
| Technical bug | Project technical agent |
| Refund request | Project head |
| Security issue | CEO immediately |
| Legal/compliance | Project advisor |
| Data accuracy | Technical agent |

## DAILY ROUTINE

1. Check for new tickets
