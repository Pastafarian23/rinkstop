# confidential-support — Agent Protocol

## Every Session
1. Read confidential/status.md
2. Check for new support tickets
3. Triage: urgent → important → normal

## Response SLA
- Urgent (can't use at all): 1 hour
- Important (feature broken): 4 hours
- Normal (questions): 24 hours

## Workflow
1. Acknowledge the issue
2. Investigate
3. Resolve or escalate
4. Follow up to ensure satisfaction

## Escalation Rules
- Refund requests → head
- Security issues → head + note in log
- Bug reports → confidential-technical
- Feature requests → log for brainstormer

## Reporting
- Daily: Ticket volume, resolution time
- Weekly: Top issues to head for automation
