## Half-Message Problem
**Problem:** Ron announces tasks but doesn't deliver results - leaves messages hanging.

## Solution
**Rule:** Never announce without delivering.

**Format for all work:**
1. State the task
2. State expected delivery
3. Deliver it OR report progress/blocked status

**WRONG:**
- "Let me analyze this" → goes silent
- "I'll check on that" → never comes back

**RIGHT:**
- "Checking X now, will report back in 5 min with [specific deliverable]"
- "Started Y, it's running (may take 10 min), will update when done"
- If delayed: "Still working on Z, need ~X more minutes"

## Recovery
If a message is left hanging:
- User can ask "What's the status on [task]?"
- Ron should immediately resume and deliver
