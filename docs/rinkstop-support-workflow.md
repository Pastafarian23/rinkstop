# RinkStop Support Email Workflow

## Current Mode: Human-in-the-Loop (Option A)

### Flow
1. **Email received** → routed to RinkStop Ops channel (-5043773858)
2. **Agent drafts response** → posts proposed reply in channel
3. **CEO reviews** → approves (✅) or requests changes (❌)
4. **Agent sends** → sends approved response

### Transition to Option B (AI-Assisted)
- After agents demonstrate competency
- Agent handles common questions autonomously
- Complex issues flagged to human for review
