# TopShelfToker — Printful + Shopify Infrastructure

## Setup Overview

```
Arnel's Designs (zip)
        │
        ▼
   Printful Store     (upload designs, generate mockups)
        │
        ▼ (auto-sync via Printful Shopify app)
   Shopify Store      (products, variants, fulfillment)
        │
        ▼ (browserless automation)
   Store Customization (theme, nav, checkout, policies)
        │
        ▼
   Content Pipeline   (blog posts → social → email → traffic)
```

## What Printful Handles Automatically
- Product variants and pricing
- Inventory/stock levels
- Print file processing
- Shipping and fulfillment
- Order status synced back to Shopify

## What We Need Browserless For
- Theme customization and branding
- Navigation setup (collections, menus)
- Product page layout tweaks
- Policy pages (shipping, returns, privacy)
- Checkout customization
- SEO meta tags
- Testing mobile responsiveness
