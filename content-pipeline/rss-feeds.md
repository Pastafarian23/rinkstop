## Implementation Notes

### How to Use These Feeds

1. **Pick a feed reader / aggregator:**
   - Feedly (free tier: 100 feeds)
   - Inoreader (free tier: 150 feeds)
   - NewsAPI.org (programmatic, $0-449/mo)
   - Custom script pulling RSS via Python/Node

2. **Categorize by niche:** Group feeds into the 6 SativaExchange categories

3. **Daily pull:** Scan headlines, flag 3-5 stories worth covering

4. **Feed into templates:** Take selected stories → plug into the prompt templates

### Automated Pipeline (Future)

- RSS → Zapier/Make → AI draft → Google Docs/Notion review → WordPress publish
- Or: RSS → Custom script → API call to AI → Draft saved to drafts folder

### Cost

- RSS feeds themselves: **FREE** (all sources above offer free RSS)
- Feed reader: **FREE** (Feedly/Inoreader free tier)
- AI drafting: **FREE-$10/mo** depending on provider
- **Total to start: $0**
