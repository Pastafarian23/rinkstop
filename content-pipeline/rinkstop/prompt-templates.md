# RinkStop Content Prompt Templates
## Copy-paste into your AI tool — tuned for hockey across all levels

---

## TEMPLATE 1: Hockey News Social Post

```
Write a social media post for RinkStop (rinkstop.com).

SOURCE MATERIAL:
[PASTE NEWS ARTICLE OR HEADLINE HERE]

PLATFORM: [Twitter / LinkedIn / Facebook / Instagram]
MAX LENGTH: [Twitter: 280 chars / LinkedIn: 1300 chars / Facebook: 200 words]

TONE: Passionate, community-focused, enthusiastic. Like a hockey coach talking to the team. Use "we", "our community", "y'all."

INSTRUCTIONS:
1. Lead with WHY this matters to hockey people
2. Keep it conversational — like you're posting between periods
3. Tie it to RinkStop naturally (directory listing, CoachBoard drill, Scoresheet feature)
4. End with a CTA or community question
5. Include 2-3 relevant hashtags
6. Use emojis naturally (🏒🥅🏟️)

DO NOT:
- Sound like a press release
- Use corporate jargon
- Forget the community angle

EXAMPLE HASHTAGS: #HockeyTwitter #YouthHockey #Coaching #NHL #IIHF #RinkStop
```

## TEMPLATE 2: Coaching Tips Blog Post (CoachBoard Tie-In)

```
Write a coaching tips blog post for RinkStop (rinkstop.com).

STRUCTURE: Story/Scenario → Tip/Drill Explanation → How CoachBoard Helps → CTA
LENGTH: 400-600 words
TONE: Coach-to-coach, practical, encouraging

TOPIC: [INSERT COACHING TOPIC — e.g., "breakout passes", "forechecking systems", "power play setups"]

INSTRUCTIONS:
1. Open with a real game scenario or coaching challenge
2. Explain the coaching concept clearly (assume mixed audience — some new coaches)
3. Describe a specific CoachBoard drill to practice it
4. Include practical tips the coach can use at next practice
5. Link back to RinkStop CoachBoard for the drill visualization
6. End with encouragement — coaching is hard, keep going

DO NOT:
- Write in academic/clinical tone
- Assume all readers are experienced coaches
- Forget the CoachBoard feature tie-in

SPECIAL: If the topic involves age-specific coaching (youth vs. juniors vs. adults),
state the age group clearly in the intro.
```

## TEMPLATE 3: Facility Spotlight

```
Write a facility spotlight post for RinkStop (rinkstop.com).

STRUCTURE: Rink Introduction → What Makes It Special → Practical Info → CTA
LENGTH: 300-500 words
TONE: Enthusiastic, community-building, welcoming

FACILITY: [INSERT RINK NAME, LOCATION, KEY FEATURES]

INSTRUCTIONS:
1. Lead with what makes this place unique (oldest rink? newest facility? community hub?)
2. Include practical details: location, amenities, programs offered
3. Tell a human story — the people who run it, the community it serves
4. If in a growth market, emphasize the "Local Scenes" angle — how hockey is building in unexpected places
5. Link to the facility in the RinkStop directory
6. End with a call to visit or add their own rink to RinkStop

DO NOT:
- Sound like a dry directory listing
- Forget the human element
```

## TEMPLATE 4: "Local Scenes" — Country-Specific Hockey Perspective

```
Write a "Local Scenes" blog post for RinkStop (rinkstop.com).

STRUCTURE: Local Hockey Scene → Global Connection → RinkStop's Role → CTA
LENGTH: 400-700 words
TONE: Proud, inspiring, bridges cultures through hockey

TOPIC: [INSERT — e.g., "growing youth hockey in the Philippines", "Canadian junior hockey scene", 
         "European hockey league expansion"]

INSTRUCTIONS:
1. Start with a specific local hockey moment or story from any country
2. Connect it to bigger trends in global hockey
3. Highlight what makes this country's hockey scene unique (climate, culture, growth trajectory, history)
4. Show how RinkStop helps connect local hockey to the global community
5. Include practical resources (find rinks, join leagues, CoachBoard drills adapted for local conditions)
6. End with an inspiring note about hockey being for everyone, everywhere

SPECIAL NOTE: This is RinkStop's unique differentiator. Nobody else covers country-specific hockey 
in the context of global hockey. Lean into the local-to-global angle hard.
```

## TEMPLATE 5: Game Management / Scoresheet Tips

```
Write a game management tip post for RinkStop (rinkstop.com).

STRUCTURE: Common Problem → Solution → Scoresheet Feature → CTA
LENGTH: 300-500 words
TONE: Practical, coach-to-coach, helpful

TOPIC: [INSERT — e.g., "managing penalties", "tracking ice time", "recording shots on goal"]

INSTRUCTIONS:
1. Open with a real pain point coaches face during games
2. Explain the solution simply
3. Show how Scoresheet helps (digital scoresheet, PDF export, etc.)
4. Include a quick "how to" for using the feature
5. End with encouragement — good game management = better experience for everyone

DO NOT:
- Sound like a software manual
- Over-explain hockey rules (assume some knowledge)
```

| Game management tips | Template 5 (Social/Blog) | 15-20 min | Rules changes, officiating |
