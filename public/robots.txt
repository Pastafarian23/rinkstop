# RinkStop robots.txt
#
# Strategy (2026-10-13 update, Arnel 2026-10-13 12:31 CDT directive):
#
#  1. ALLOW every AI bot that cites us in answers (ChatGPT, Perplexity,
#     Claude, Google AI Overviews, Gemini, Copilot, Mistral, xAI/Grok,
#     DeepSeek, Qwen, Meta, etc.). We want to be cited.
#  2. ALLOW every AI bot that trains foundation models on the open web
#     (GPTBot, ClaudeBot-train, Google-Extended, CCBot, etc.). Good for
#     the broader AI ecosystem; some of these don't cite back but
#     blocking them hurts our long-term discoverability.
#  3. BLOCK commercial SEO scrapers (Ahrefs, Semrush, etc.) — they
#     resell our data to competitors with no benefit to us.
#  4. BLOCK uptime / monitoring bots (UptimeRobot, Pingdom, etc.) —
#     they ping / healthcheck pages and inflate analytics with no
#     user-facing value.
#  5. llms.txt is the canonical AI-citation index. We expose a full
#     reference at /llms-full.txt for deep ingestion.
#
# Sitemaps (last 7):
#   /sitemap.xml, /sitemap-rinks, /sitemap-teams, /sitemap-players,
#   /sitemap-leagues, /sitemap-locations, /sitemap-news
#   /llms.txt (AI-citation index)
#
# Updated 2026-10-13.
