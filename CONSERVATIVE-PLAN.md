# Conservative Spending & ROI Framework

## Core Rules

### 1. Always Validate Before Spending
Before any paid tool, service, or API:
- ✅ Confirm with Arnel FIRST with cost estimate
- ✅ Verify free tier is insufficient
- ✅ Show exact cost
- ✅ Get explicit go-ahead

### 2. Hard Budget Limits
| Project Stage | Max Spend | Approval |
|--------------|----------|----------|
| Ideation/Testing | $0 | N/A (free only) |
| MVP/Launch | $50/project | Required |
| Scaling | $200/project | Required |

### 3. ROI Before Execution
For every project, answer upfront:
- **What's the goal?** (e.g., get first sale, launch MVP)
- **What's the realistic timeline to revenue?**
- **What's the break-even point?**
- **What's the downside if it fails?** (just time? or money too?)

---

## Project Evaluation Checklist

Before starting any paid initiative, ask:

### Viability Questions
- [ ] Is there a clear path to revenue? (What, to whom, how much?)
- [ ] Is there existing demand? (Searches, competitors, audience size)
- [ ] Can we compete? (Differentiation, unique value)
- [ ] Is the timing right? (Market conditions, seasonality)

### Financial Questions
- [ ] What's the cost to launch (minimum viable)?
- [ ] What's the cost to scale?
- [ ] How many sales needed to break even?
- [ ] What's the max loss if it fails?

### Effort Questions
- [ ] Who's doing the work?
- [ ] How long until something is sellable?
- [ ] What's the opportunity cost?
